# Играмир · Telegram Mini App

В браузере приложение работает как демо. При запуске из меню бота или кнопки после /start оно отправляет менеджеру контакты, тираж, параметры, исходный эскиз и концепт. Превью создаётся локально из загруженного изображения.

## Запуск

Нужны Python 3.9+, отдельный бот, ID чата менеджеров и публичный HTTPS-адрес. Добавьте бота в этот чат. Для личного чата менеджер сначала открывает бота и нажимает Start.

Задайте параметры в настройках окружения хостинга.

- `IGRAMIR_TELEGRAM_BOT_TOKEN` — секрет из BotFather.
- `IGRAMIR_TELEGRAM_MANAGER_CHAT` — числовой ID чата, куда поступают заявки.
- `IGRAMIR_TELEGRAM_APP_URL` — публичный HTTPS-адрес сервера, например `https://app.example.com`.
- `IGRAMIR_PORT` — локальный порт, по умолчанию 8080.

Запустите `python3 telegram_server.py` и направьте HTTPS-прокси на `127.0.0.1:8080`. Прокси должен пропускать загрузки до 15 МБ и сохранять путь запроса. Бот настраивает кнопку меню при запуске и использует long polling. Запускайте один экземпляр процесса для выделенного бота без активного webhook.

Для приёмки откройте бота на телефоне, отправьте /start, загрузите тестовый эскиз, выберите параметры и отправьте тестовую заявку. Проверьте, что у менеджера появились карточка с параметрами и два вложения.

Статическая приватная публикация Sites предназначена для демонстрации. Рабочий Telegram-режим использует тот же интерфейс с сервером и маршрутом `/api/telegram/requests`.

## GitHub Pages

Публикуйте каталог проекта visualizer как отдельный репозиторий. В Settings → Pages выберите GitHub Actions. Workflow публикует только dist после обновления ветки main.

Для подключения Telegram задайте переменную репозитория IGRAMIR_API_ORIGIN с HTTPS-адресом Python-сервера без завершающего слеша. На сервере задайте IGRAMIR_TELEGRAM_APP_URL полным адресом страницы GitHub Pages, включая путь репозитория. Токен бота хранится в окружении Python-сервера.
